# 异世界种田 (Isekai Farming)

纯前端增量挂机 RPG：前期手动采集，逐步解锁制作与装备，后续往自动化生产、战斗（攻/防/血）、种田经营发展。

**技术**：原生 HTML/CSS/JavaScript + Canvas 2D，无第三方依赖、无构建步骤，纯静态站点，可直接部署到 GitHub Pages。手机（触屏）与桌面（鼠标）统一使用 pointer 事件，固定 480×800 逻辑分辨率等比缩放。

## 本地运行

- 直接双击 `index.html` 即可游玩；或
- 起个本地服务器：`python3 -m http.server 8000`，浏览器打开 <http://localhost:8000>

## 当前内容（v0.1.0 新手篇）

- 主菜单：新游戏（可选跳过开场剧情）/ 继续游戏 / 设置（文字速度、删档）
- 开场剧情：996 猝死 → 异世界 → 神明赐予加护【田园百景】（饿不死，血量基础上限固定）
- 手动采集：草丛（浆果+树叶）、铁矿脉（铁矿）、斧头砍树（木材）
- 食物系统：最多 3 份同时生效，提高生命/法力上限，不吃不会死
- 制作链：树叶生火 → 铁矿+火冶炼铁锭 → 铁斧/铁剑/铁甲
- 任务链：神明指引的 7 个新手任务，完成后提交领奖励
- 存档：localStorage 自动保存，删档不丢设置

## 目录结构

```
index.html          入口
css/style.css       页面样式（画布居中、禁用滚动缩放）
js/i18n.js          多语言核心：t()/tf() 取文案，缺失时回退中文
js/lang/zh-CN.js    中文语言包（全部游戏文案）
js/lang/en-US.js    英文语言包
js/data.js          数值与机制配置（物品/配方/任务/速度，不含文案）
js/game.js          状态、存档、游戏规则、对话系统
js/ui.js            Canvas 即时模式 UI 辅助与图标绘制
js/scenes.js        场景：主菜单/剧情/主界面/各面板
js/main.js          画布缩放、主循环、输入分发
```

## 多语言

- 界面语言在「设置」里切换，当前支持中文 / English。
- 文案与数据分离：`js/data.js` 只放 id 和数值，所有文字在 `js/lang/*.js`。
- 新增语言：复制 `js/lang/en-US.js` 为新文件（如 `ja-JP.js`），翻译全部值，
  然后在 `index.html` 里加一行 `<script src="js/lang/ja-JP.js"></script>`，
  设置面板会自动出现该语言选项。
- 语言包里 `{name}` 这类占位符由 `tf()` 在运行时替换。
